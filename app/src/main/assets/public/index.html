HARDWARE INTEGRATION

Hardware controller (HC-05)

Mode: Bluetooth Classic SPP/RFCOMM at 9600 baud, available only in the Android app. Web Bluetooth (BLE) cannot connect to an HC-05, so a browser or installed PWA never controls hardware.

ᛒ
Checking browser support…No hardware connection is active.
NOT CONNECTED
Troubleshooting. Pair the HC-05 first in Android Settings → Bluetooth (PIN is set on the module, commonly 1234 or 0000). Allow "Nearby devices" when asked. Check the HC-05 is powered and not connected to another phone. A reply of OK:… or STATUS:… only means the Arduino accepted the command; confirm the light itself changes. If the link is connected but the controller never replies, re-upload the sketch and check the HC-05 baud rate (9600) and the Mega pin 10/11 wiring.
